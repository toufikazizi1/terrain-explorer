# Terrain Explorer — مستكشف التضاريس

واجهة خرائط تفاعلية باللغة العربية مبنية باستخدام HTML وCSS وJavaScript وLeaflet.

## المزايا
- خريطة شوارع OpenStreetMap.
- طبقة تضاريس OpenTopoMap.
- صور أقمار صناعية من Esri.
- البحث عن المدن والأماكن عبر Nominatim.
- تحديد موقع المستخدم بعد موافقته.
- عرض الإحداثيات والارتفاع التقريبي عبر Open-Meteo.

## التشغيل
افتح `index.html` عبر خادم محلي أو انشر المستودع باستخدام GitHub Pages.

## ملاحظات
هذا المشروع واجهة خرائط مستقلة، ولا يتضمن بيانات LiDAR أو أدوات مسح/تحليل تضاريس احترافية. تعتمد الطبقات والبيانات على خدمات خارجية وقد تخضع لحدود الاستخدام والتوفر.
